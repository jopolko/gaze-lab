2026-11-21: owner likes the Interzone realm and asked for more worlds tied to literary figures (Asimov, Eric Frank Russell, Burroughs and a couple more). Decision: keep neon-noir as the frame; the Rail keeps an Index of Paused books; each Recovered Book is a 1-3 min optional gate-world with an invented in-game title (no author names or text in-game; thanks page in credits). First five: Newsprint Bazaar (Interzone), Soft Machine (Melt), Foresight Vault (Asimov psychohistory = Predicted You), Go-Slow (Russell Great Explosion, stillness pays), Hornet Run (Russell Wasp, domino chain).

**Why:** literature is what thought control targets, and cyberpunk grew from these writers.
**How to apply:** see doc for all ten and IP notes; optional pull-offs so they never get in the way of the ride. Related: [[downfall-complete-game]] [[downfall-tone-neon-noir]]
